# Tacker — Package Dashboard

A single-page dashboard for tracking UPS and FedEx packages.

- Paste a tracking number; the carrier is detected automatically (UPS `1Z…`, FedEx 12/15/20/22 digits).
- Set a nickname, destination and status for each package.
- Summary tiles for in transit / out for delivery / delivered / problem, grouped by destination.
- "Track on UPS/FedEx" links open the carrier's live tracking page.
- Data is stored in the browser's `localStorage` only.

Open `index.html` in a browser to use it.
